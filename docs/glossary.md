# Glossary

One word for each notion, the same on every board, at the command line, for
an agent and on these pages.

| term | what it is |
|---|---|
| **task** | a piece of work, numbered, standing in one column |
| **column** | where a task stands: `backlog`, `todo`, `current`, `done`, and three for work that is stopped |
| **band** | the three columns of stopped work, `blocked`, `watching` and `paused`, drawn under the others |
| **order** | the place of a task among the tasks of its column, the one you set |
| **priority** | `low`, `normal`, `high` or `critical` |
| **label** | a word a task or an objective carries; it may have a colour |
| **step** | a piece of a task, done or not, named by its place in the task |
| **blocker** | a task in the way of another; a blocked task waits on its blockers |
| **unblocked** | a task nothing stops: no blocker still open, no reason said |
| **link** | two tasks said to go together, both ways |
| **deadline** | the day a task or an objective is wanted by |
| **estimate** | how long a task or an objective should take |
| **focus** | the tasks you are working on now; their time runs |
| **focus session** | how long a task stays in focus before cairn asks to renew it |
| **objective** | what work is for; tasks serve it, and it counts how far along they are |
| **parent** | the objective another sits under, two levels deep at most |
| **reached** | an objective done with |
| **report** | what was done for an objective over a period, and the time it took |
| **series** | a task that comes back by a rule |
| **rule** | when a series comes back: `--every "monday 9:00"` |
| **occurrence** | one task a series made |
| **trace** | everything that happened to a task or an objective, who did it and when |
| **time spent** | the time a task was in focus |
| **timesheet** | the time spent, day by day |
| **notes** | the folder beside a task where what was done on it is written; `context` in its JSON |
| **view** | the board's filters kept under a name |
| **filter** | what narrows the board: a column, a priority, a label, an objective, a deadline |
| **archive** | where done tasks go to leave the board; they are kept |
| **store** | the file holding a board's tasks and objectives |
| **workspace** | a named folder holding a store and its notes |
| **settings** | how a board behaves; the keys `cairn config` sets |
| **tab** | a part of the boards: tasks, objectives, time, series |
| **theme** | the colours the boards wear |
| **backup** | a copy of a store, made and restored by `cairn backup` |
| **migration** | a change to the store's shape that a newer cairn applies |
| **MCP server** | what lets an agent work on the board: `cairn mcp serve` |
| **plugin** | the Claude Code plugin that ties a session to a task |
